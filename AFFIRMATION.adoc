== What this is, and how it works

This file is a dated, signed snapshot of what can honestly be claimed about
*Cadastra* at one exact commit. It is the third file of the README / EXPLAINME /
AFFIRMATION trio. The README says where the project is going. EXPLAINME says
how it is built. This file says what was *true and checkable* at the anchor
below.

Every claim here comes from running the project's own checks in the session
that wrote this file. Where the README, the Justfile or memory disagree with a
live run, the live run wins and the disagreement is recorded.

The owner lands this file with a signed git commit. That signature over this
content, at the anchored commit, is what makes the affirmation attributable.

== The epistemic contract

This document records best belief at the timestamp below. It is not a
guarantee of correctness. The only guarantee is *no intentional overclaim*.
Where something was checked, it says how. Where something was not checked, it
says so. A claim that later proves false is an error to fix, not a lie.

You are invited to refute any claim here with a failing run, a
counter-example or a contradicting source.

== The honest state (one breath)

At the anchor, the Idris2/Zig ABI seam builds and its 9 Zig tests pass, the
aspect and all four workflow self-tests pass, and the Agda and Coq proof
files check. Not everything checks: the golden path `just test && just
quality` fails at its shellcheck step, the Lean and Idris2 verification proofs
fail, and the e2e suite is an unfilled template that runs zero tests.

=== What is solid (and how we checked)

* `just build` succeeds. `zig build` compiles the FFI, and `idris2 --build
  abi.ipkg` builds all 3 ABI modules. The log was read for `Error:`, not just
  the exit code: no errors, and two shadowing warnings in `Abi.Layout`, both
  for the implicit `n` at lines 87 and 89.
* `just test` succeeds. `zig build test --summary all` reports `9/9 tests
  passed` (3 in `src/main.zig`, 6 in `test/integration_test.zig`).
* `just aspect` passes 3 of 3: SPDX headers present, and no `believe_me`,
  `assert_total`, `Admitted`, `sorry` or `unsafeCoerce` in source.
* All four `tests/workflows/*` self-tests pass: lock sync 18/18 (including
  the case that runs the checker over the repository's own workflows),
  dogfood gate 7/7, foundation CI fixes 5/5, and workflow validation with
  0 errors and 4 warnings (two recommended workflows absent:
  `npm-bun-blocker.yml`, `ts-blocker.yml`).
* `verification/proofs/agda/Properties.agda` checks with Agda (rc=0, no
  errors). `verification/proofs/coq/TypeSafety.v` compiles with `coqc`
  (rc=0).
* On the anchor commit's GitHub status check rollup (read over the GraphQL
  API), 38 of 49 contexts concluded `SUCCESS`, 10 were `SKIPPED` and 1
  failed. The successes include CodeQL, the governance policy checks, both
  lockfile checks, the secret scans, estate rules and the Hypatia scan. These

=== The honest nuance you must not lose

* *A passing e2e run here means nothing.* `just e2e` exits 0 with
  `PASS=0 FAIL=0 SKIP=0`. `tests/e2e.sh` is still the template; its sections
  are `TODO` comments.
* *`just bench` measures the build, not the product.* It times workflow
  validation and the Zig build and test, roughly 20 to 100 ms each.
* *`just readiness` reports no grade.* `docs/status/READINESS.adoc` records
  no CRG grade.
* *Two Idris2 trees, two results.* The ABI under `src/interface/Abi/` builds.
  The separate proof tree under `verification/proofs/idris2/` does not (see

== Reproduce it yourself

From a clone checked out at the anchor commit:

[source,bash]
----
git checkout 0dac3dc8824e41d795386f90441ac14d5236b2fd
just build && just test aspect e2e
just quality                                               # rc=123 at lint
(cd src/interface/ffi && zig build test --summary all)   # 9/9 tests
for t in tests/workflows/*.sh; do bash "$t"; done         # lock-sync: 18/18
(cd verification/proofs/agda && agda Properties.agda)
(cd verification/proofs/coq && coqc TypeSafety.v)
(cd verification/proofs/lean4 && lean ApiTypes.lean)      # rc=1
(cd verification/proofs/idris2 && for f in Types.idr ABI/*.idr; do idris2 --check "$f"; done)  # look for "Error:"
----

Agda needs agda-stdlib. Point `AGDA_DIR` at a directory whose `libraries` file
names the stdlib's `.agda-lib` and whose `defaults` file says
`standard-library`.
