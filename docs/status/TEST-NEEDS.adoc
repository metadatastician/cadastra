== Instantiation note (2026-07-27)

This repo was minted from the RSR template but left un-instantiated in
several places: literal `{{PLACEHOLDER}}` tokens, template-only validation
machinery, and fake `echo "TODO"` Justfile stubs. As part of curing that:

* `scripts/validate-template.sh` and `tests/e2e/template_instantiation_test.sh`
  were *removed* — they existed only to validate/instantiate the RSR template
  itself, not to test Cadastra.
* `src/interface/ffi/test/integration_test.zig` was converted from a
  documentation-only placeholder test into real integration tests against
  the actual exported FFI (`cadastra_init`, `cadastra_process`, ...).
* `src/interface/ffi/build.zig` was wired with a real `test` step (it
  previously did nothing).
* `benches/template_bench.sh` had its two template-validation-only
  benchmarks removed; it still benchmarks the Zig build/test and workflow
  validation, which are real.

The counts and status below reflect the *current* state, not the prior
template-validation-focused snapshot.
