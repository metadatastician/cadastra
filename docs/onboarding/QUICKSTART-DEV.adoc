= Cadastra — Quick Start for Developers
:toc:
:toclevels: 2

== Tech Stack

Bash (the `tools/estate-migration-toolkit/` scan + migration scripts, this
repo's real payload) plus Idris2 (ABI type + layout proofs) and Zig (FFI
implementation) for the RSR scaffold's reference ABI/FFI seam under
`src/interface/`.

== Set Up Development Environment

=== Option A: Guix (preferred)

[source,bash]
----
guix shell -D -f guix.scm
----

=== Option B: Manual

[source,bash]
----
git clone https://github.com/metadatastician/cadastra.git
cd cadastra
just setup-dev
----

== Build

[source,bash]
----
just build
----

== Test

[source,bash]
----
just test
----

== Project Structure

[source]
----
cadastra/
├── tools/estate-migration-toolkit/  # The scan + migration toolkit
├── docs/status/estate-triage-report.csv  # Latest scan output
├── src/interface/Abi/    # Idris2 ABI definitions (RSR scaffold example)
├── src/interface/ffi/    # Zig FFI bridge (RSR scaffold example)
├── tests/                # Test suite
├── docs/                 # Documentation
├── .machine_readable/    # Checkpoint files (STATE, META, ECOSYSTEM)
├── Justfile              # Task runner recipes
├── guix.scm              # Guix environment
└── 0-AI-MANIFEST.a2ml    # AI agent entry point
----

== Key Recipes

[source,bash]
----
just build          # Build the ABI/FFI seam (zig build)
just test           # Run tests (zig build test)
just doctor         # Self-diagnostic
just lint           # Lint and format
just panic-scan     # Security scan via panic-attacker
just tour           # Guided tour of the codebase
----

== Before Submitting a PR

[source,bash]
----
just lint           # Format and lint
just test           # All tests pass
just panic-scan     # No new security issues
----

== Contractile Invariants

Read `.machine_readable/contractiles/must/Mustfile.a2ml` before making changes.
Key invariants that must never be violated:

* No banned languages (Nix, Node/npm, TypeScript, Python, Go, AGPL) in
  scanned/migrated repos — see `.machine_readable/descriptiles/anchors/ANCHOR.a2ml`.
* No secrets, and no state files at the repo root.
* Fail-closed: every scan step reports evidence, no silent skips.
* Release/completion claims require a hard pass, not a claimed one — see
  doctrine 2 and 10 in `CLAUDE.md`.
