= Cadastra — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

Cadastra is not distributed as a packaged binary — it is a script toolkit
(`tools/estate-migration-toolkit/`) run in place from a checkout, plus an
RSR scaffold example ABI/FFI seam. This guide covers running it, not
packaging it for a platform.

== Runtime Dependencies

* `bash`, `git` — required by every script in the toolkit
* `gh` (GitHub CLI, authenticated via `gh auth login`) — required by
  `estate-scan.sh`, `rollout-language-gate.sh`, `deprecate-poly-mcps.sh`
* `jq` — required by `estate-scan.sh` and the CI language-gate
* `bun` — required only by `migrate-deno-to-bun.sh`
* `zig` 0.16+ and `idris2` — required only to build/test the ABI/FFI seam
  under `src/interface/`

== Build from Source

[source,bash]
----
git clone https://github.com/metadatastician/cadastra.git
cd cadastra
just build-release
----

Output: N/A — this repo does not currently produce a distributable binary
or package artefact. `just build-release` builds the ABI/FFI seam under
`src/interface/ffi/` in release mode; the toolkit scripts run directly from
`tools/estate-migration-toolkit/scripts/`.

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t cadastra .
----

== Configuration

The scan toolkit takes its configuration on the command line
(`--github <orgs>`, `--local <paths>`) — see
`tools/estate-migration-toolkit/README.md`. There is no persistent config
file.

== Health Checks

[source,bash]
----
just doctor             # Full diagnostic
----

== Updating

[source,bash]
----
git pull
just build-release
----
